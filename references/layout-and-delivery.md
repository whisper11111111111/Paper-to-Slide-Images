# 布局间距与交付规范

## 固定文字区与安全区

先读取实际参考图或模板，核对画幅、字体、校徽、图片裁剪与重复元素。
在任务的布局记录中确定标题、上方观点区、正文安全区、下方结论区和来源
文字的位置；未采用的区域不必新增。每种正文版式只确定一套实际坐标。

- 同类正文页固定标题左边界与基线、上下文字区顶边与高度、正文边界。
- 固定标题至观点区、观点区至正文、正文至结论区、结论区至页脚的间距。
  内容少时保留留白，内容多时重排正文，不逐页移动上下文字区。
- 同级模块统一内边距、栏间距与对齐方式。封面和结束页可以使用独立版式。
- 将坐标和间距逐页写入生图提示词；参考图只提供风格，不能保证模型自动
  复现同一位置。固定锚点偏差目标不超过画幅高度的0.3%，超出时校正。
- 需要严格一致时，可在页面设计阶段预留文字区，由统一的原生文字层承载
  标题或结论。不能把生成图中已有的文字再叠一遍，造成重影。

以下仅为1280×720正文页的可调整起点，不是所有画幅或模板的硬编码参数：

| 区域 | 起始参考 |
| --- | --- |
| 左右边界 | x=70至1210 |
| 标题 | x=70，基线y=65，无编号栏 |
| 分隔线 | y=105 |
| 上方观点区 | y=122，高44，文字基线y=152 |
| 正文安全区 | y=186至599 |
| 下方结论区 | y=611，高43，文字基线y=640 |
| 来源文字 | 模板允许范围内的固定基线，不含页码 |

不同画幅按比例重新计算，再检查实际文字容量。模板已有结构时以模板
安全区为依据；背景曲线、图案和校徽也占用空间，个人信息避开高亮曲线。

## 不生成页码与展示性标号

默认不生成页码、总页数、标题前“一、”“二、”、章节角标“01/02”、
卡片编号、圆圈序号和流程步骤前的数字。使用标题、位置与连线表达顺序，
不改用字母或罗马数字补回序号。

参考图或示例已有此类编号时也不沿用。清除后重新安排标题与模块，不留
空编号栏；检查生成图片和PPT叠加层，避免再次自动添加。原生模板的母版
或版式含编号时，使用相应演示文稿流程支持的方式处理，不破坏校徽与主题。

保留数据、单位、日期、学号、材料牌号、样品号、配方号、标准号、公式编号
和文献引用等有实质含义的标识。原文图中的证据性子图标签不随意擦除。
内部文件名、清单ID与顺序编号不受影响。用户明确要求编号或完整原样保留
页面时，以该次指令为准。

## 信息拥挤时先重新排版

先精简重复措辞，再调整图文比例、列宽和模块顺序；密集表格可上下排列，
不要把整页等比缩小塞入正文区域。保留必要数据、单位、来源与限定条件。
优先语义换行、扩大文字容量，局部字号调整放在最后，不整套缩小正文。
连接线避开文字，科学图不裁掉坐标、单位、色标或关键结构。

图片式页面中的正文和表格仍为像素内容。用户要求逐项可编辑时，转用
原生对象流程，并如实区分原生表格、网格文字和独立科学图片的编辑能力。

## 逐页复核实际PPTX

- 先查看总览，再以一致、可读的大小检查每一页；不能只检查拼图或SVG。
- 核对文字、公式、数据、工况、引用、流程方向、换行、边距和固定锚点。
- 检查无新增页码或展示性标号，尤其检查参考图原编号区域和PPT覆盖层。
- 模板任务比较源版与成品的校徽、颜色、文字位置和页脚，确认没有高亮
  背景遮蔽个人信息、重影或丢失必要元素。
- 默认无演讲稿、旁白、动画和自动播放；只有用户要求时启用相应功能。
- 使用当前工具的结构检查、图片嵌入检查、文本/备注检查。目标应用可用时
  打开并渲染实际PPTX；否则如实说明验证范围，不冒称PowerPoint验证。
- 出现图片内容类型冲突、重复扩展名声明或对象替换失败时，修复素材或
  受支持的构建设置后重新导出。不能靠“导出成功”判断文件可正常打开。
- 最终交付目录仅放最终版和需要的预览、图片、文献包；调试稿保留在工作区。

## 方法借鉴

本规范吸收了演示文稿工作流中对真实模板的检查、模板结构复用、先重排再
缩字号、逐页视觉审阅与导出后兼容性检查的方法。规则在本技能内完整表达，
无需安装另一技能才能理解。实际构建仍遵守当前可用工具的接口与限制，
不混用不同导出引擎的内部文件，也不把图片式PPT宣称为全文可编辑。
